# 案件设计方法论 — 如何写出好玩又能过校验的案件

本文回答一个问题：**同样符合格式，为什么有的案件好玩、有的无聊？** 以下是从玩法本质推导出的设计法则。

---

## 一、玩法本质：三重快感

NZCP 的乐趣来自三个层次，设计时必须逐层兑现：

| 层次 | 快感 | 设计手段 |
|---|---|---|
| **发现** | "这段文字不对劲" | 线索藏在自然语句里，而非强调式总结；用具体数字、时间、颜色、体貌特征作饵 |
| **连接** | "这两条放在一起，矛盾出现了！" | 两条独立文档中的信息能精确咬合（时间 vs 时间、特征 vs 特征、物证 vs 证词） |
| **逆转** | "原来他一直在说谎！" | 结论卡形成链条后，表面案情整个翻转；结案演出把链条"播放"出来 |

反面：如果线索卡本身就把答案写全了（"证词与法医结论矛盾"），玩家就只剩"点击"而无"推理"。**线索卡只陈述事实，绝不陈述推理。**

## 二、诡计类型库（选择其一作为核心）

### 1. 时间诡计（最经典、最适合案宗形式）
表面：目击者称某时刻看到嫌疑人。
真相：该时刻与死亡/案发时间存在硬冲突；目击者记错、撒谎或看到的是别人。
> 关键设计：把"目击时间"和"法医/监控时间"分放在两份文档；玩家配对即破。

### 2. 身份错认
表面：证人认出了嫌疑人（衣着/背影/特征）。
真相：证人描述的体貌特征与嫌疑人档案不符，而与另一人吻合。
> 关键设计：证词给 1-2 个具体特征（"肩膀宽""走路瘸"），另一份文档给某人的特征，重叠即指向。

### 3. 物证栽赃
表面：现场发现属于嫌疑人的物品。
真相：该物品的物理状态（干燥/损坏/尺寸）证明它不可能被用于作案。
> 关键设计：物证的"状态描述"是命门——干燥的雨衣、崭新的鞋底、断掉的拉链。

### 4. 现场伪造
表面：密室/自杀/意外。
真相：凶手提前布置（破坏监控、伪造遗书、从内部上锁的机关）。
> 关键设计：给出"伪造成本"类线索（被扯断的线缆、不合时宜的摆放），配合一份"看似无关"的报告。

### 5. 证词污染
表面：多名证人互相印证。
真相：证人们听信了同一个传闻/被同一人引导，所谓"互相印证"其实是同一信息源。
> 关键设计：两份证词细节高度雷同但用词一致——"连错都错得一样"。

### 6. 动机反转
表面：嫌疑人因财/情杀人。
真相：真凶是被忽略的"受害者一方"，动机藏在账目、信件、旧报道里。
> 关键设计：账本/信件中的数字与日期，与"争吵传闻"的线索组合出完整动机链。

**选择建议**：新手案件用 1 或 3（逻辑最硬、玩家最容易获得"啊哈"）；标准案件可叠加 1+3（时间+物证双矛盾）。

### 复合诡计与三重翻转编排（难度 4-5）

硬核案件可把多个诡计类型叠成**三重翻转**，每层翻转必须独立引爆、层层递进：

| 层 | 翻转对象 | 典型手法 | 引爆材料 |
|---|---|---|---|
| 翻转一 | **世界观**（"这场案子的前提就不成立"） | 对核心物证的重新解读——被偷的东西是假的/被烧的东西没烧/死者早已知晓 | 一份独立化验/检验报告，由铁证链成立后解锁 |
| 翻转二 | **手法与不在场** | 拆"完美证词"：系统日志/权限记录/门禁制度与证词逐句对质 | 系统类文档（日志/档案），由锁定内部人后解锁 |
| 翻转三 | **人格与栽赃** | 一个反复埋设的细节特征（惯用手/习惯/旧伤）最终指向栽赃 | 特征线索初始文档就给（埋得早、爆得晚） |

编排原则：①每层翻转由**上一层解锁的材料**引爆（翻转一的材料靠铁证链解锁、翻转二靠内鬼锁定解锁）；②翻转之间穿插鲱鱼排除题（张弛起伏，不一路翻到底）；③最后用"动机闭环"议题把三层收进一条线。

## 三、线索链设计模式

### 模式 A：线性链（适合教学案件）
```
线索1 + 线索2 → 结论A
线索A？不，结论A + 线索3 → 结论B
结论B + 线索4 → 结论C（结案依据）
```
优点：引导清晰；缺点：玩家只需按顺序推进。**控制在 3-4 题内使用。**

### 模式 B：并行汇合（推荐的标准结构）
```
线索1 + 线索2 → 结论A（洗清被告）
线索3 + 线索4 → 结论B（锁定特征）
结论B + 线索5 → 结论C（锁定真凶）
结论A + 结论C → 结案（双重要求）
```
优点：玩家有两条探索线，节奏张弛；结案需要"洗冤+擒凶"两个结论，仪式感强。

### 模式 C：双向验证（高分设计）
同一条线索被两个不同议题使用（第一次用来推翻时间，第二次用来锁定身份），玩家会获得"这条线索真关键"的满足感。

**节点数量参考**：3-5 个结论、4-6 个议题、12-20 条线索。

## 四、误导设计（红鲱鱼）

没有误导的案件像填表，要有 1-2 个"合理但不成立"的诱饵：

1. **可疑但无罪的嫌疑人**：行为诡异（深夜徘徊、撒谎关于小事），但关键矛盾最终证明其无罪。结案时给玩家"差点冤枉好人"的紧张感。
2. **半真半假的证词**：证人不是在说谎，而是记错了/被引导了——比纯谎言更真实。
3. **无关但扎眼的物证**：湿透的烟头、翻倒的展示柜——可做氛围细节，也可在结案后揭示"那是另一个故事"。
4. **误导的注意边界**：诱饵线索必须**最终能被排除**（如有议题解释它），否则玩家会觉得被耍。

两个高阶技术（难度 4-5，第 2 话《逆转的雾夜画廊》验证有效）：

**A. 拼后拆机关**——把"建立错误信念"做成一道议题：让玩家**亲手把检方的铁证链拼完整**（议题答案 = 前科+现场物证+行踪疑点，产出结论"如山的『铁证』"），结论文案里埋一句"链条再漂亮，也只是『表面』"——下一题立即掀翻。玩家亲手建立的信念被亲手推翻，落差远大于被动听检方陈述；且拼装过程让玩家逐条细读了每项证据，翻转时的回味更深。

**B. 鲱鱼自反点**——干扰嫌疑人的每条"铁证"在**埋设时就预埋自反点**，且自反点随初始文档一并给出（藏在深挖块/不起眼的备注里）：手套的 DNA 旁跟着"磨损属惯用左手者"、湿雨衣的解释旁跟着"除湿机故障半月"、失联 40 分钟旁跟着"地下无信号"。玩家推到后期回头翻卷宗才会惊觉——**答案从一开始就摆在明面上**。这是"渐进式信息释放"的反向运用：不是不给信息，而是把拆解误导的钥匙提前交给玩家、却让它毫不起眼。

## 五、难度分级配置表

| 难度 | 文档数 | 线索数 | 议题数 | 答案卡数 | 解锁结构 | 圈选/dig/hidden | 演出量 |
|---|---|---|---|---|---|---|---|
| 1 入门 | 6-8 | 10-13 | 3 | 2 | 全初始，1 份隐藏 | 无（金线直摘教学） | 序章 4 句 / 结案 8 句 |
| 2 简单 | 8-10 | 13-16 | 4 | 2-3 | 1-2 份隐藏 | 关键词 0-2 / dig 0-1 / hidden 0 | 同上 +1 处 fx |
| 3 标准 | 10-13 | 16-22 | 5-6 | 2-3 | 2-3 份隐藏 | 关键词为主 / dig 1-2 / hidden 0-1 | 结案 12 句 |
| 4 进阶 | 12-16 | 20-28 | 6-8 | 3-4 | 链式解锁（结论解锁文档） | 关键词全覆盖 / dig 2-3 / hidden 1-2 | 多段演出 |
| 5 硬核 | 15-20 | 26-40 | 8-10 | 3-4 | 多级解锁 + 支线 + 拼后拆/三重翻转 | 关键词全覆盖（30+ 处圈选点）/ dig 3-4 / hidden 2 | 完整三幕感 |

**首案建议 1-2 级**；让玩家在 15-25 分钟内获得一次完整"读→摘→连→逆转"体验。

### 渐进式设计三原则（难度 3+ 必读，直接决定游玩时长）

1. **信息分批投放**：开局文档只给"表面案情"，深层材料（解剖报告、旧档案、关键信件）必须由结论解锁（`requires_findings`），占比 ≥ 40%。玩家应始终处于"知道一点，但还差一块"的状态——这是逆转裁判"调查⇄推进"循环的案宗化等价物。
2. **答案不全在明面**：关键线索不走"金线直摘"（点段落即送），而是用三件套藏起来——①**关键词圈选**（`keywords`：段落以普通文本呈现，玩家须点中"最定罪的那个字眼"，红笔圈选动画后线索才入板；证词/报告类线索的默认方式，字眼选颜色、时间、数量、反常行为）；②`dig` 深挖块（证词威慑出细节）；③`hidden` 段落（整段点击发现，适合少量兜底）。`locked_hint` 只点名"去哪份文档找材料"，绝不剧透"要圈哪个词、要深挖哪段"。
3. **试错有代价但不惩罚**：引擎规则是同一议题第一次答错只显示通用文案、第二次起才显示 `on_wrong.message`——所以玩家会先穷举再思考，恰好形成"反复端详案卷"的体验。据此要求：①干扰卡（红鲱鱼线索）要真的像答案；②高难度 prompt 不预告答案张数；③失误计数靠评分给压力，不要额外惩罚设计。

## 六、文体写作规范

### 卷宗文体（record / report）
- 客观、第三人称、带编号与术语：「死亡推定时刻：22时30分前后（误差±15分钟）」。
- 用**具体数值**建立可信度：时间、金额、次数、尺寸。
- 表格适合：时间线、账目、鉴定项目。

### 证词文体（testimony）
- 口语化、带情绪：「我、我亲眼看到的！」；含糊处正是破绽。
- 把矛盾藏在**修饰语**里："晚上9点**整**"、"**亮**黄色"、"**绝对**没错"——越强调，越可疑。
- 允许证人说出错误但"真诚"的记忆（证词污染）。

### 信件/字条文体（letter）
- 手写感：称呼、日期、口语、涂改痕迹（"月底再不还钱，就……算了，你会后悔的"）。
- 字条是动机类线索的最佳载体。

### 演出文风（逆转感）
- 短句、反问、断言。例：
  > 「证人。请看这份解剖记录——死亡推定时刻，是晚上10点30分前后。」
  > 「而你却声称，9点整看到被告『逃跑』？！被害人在一个半小时后才遇害——他跑出来干嘛的，热身吗？！」
- 结案演出节奏：亮证据 → 拆谎言 → 指认真凶 → 真凶崩溃一句 → 宣判 → 助手欢呼。
- 助手角色承担"读者代言人"功能（惊讶、提问、总结），是隐形的提示系统。

## 七、从零设计的标准流程（可直接套用）

1. **一句话诡计**：写下"表面 X，其实 Y"。
2. **画链条图**（纸上或脑内）：
   ```
   文档①(事实a) ─┐
                  ├→ 结论A → 洗清被告 ─┐
   文档②(事实b) ─┘                      ├→ 结案
   文档③(事实c) ─┐                      │
                  ├→ 结论B → 结论C ─────┘
   文档④(事实d) ─┘
   ```
3. **落表**：文档表（id/标题/关键事实/线索id）、线索表（id/label/text/来源）、议题表（id/答案/产出）。
4. **填空写 JSON**：先写 documents 与 clues（内容层），再写 findings 与 questions（逻辑层），最后写 accusation 与演出。
5. **自导自演**：假装玩家走一遍——每条 issue 所需线索是否都能在对应阶段获得？结案结论是否都可达？
6. **校验**：`python scripts/validate_case.py case.json`。

## 八、常见失败案例（自查清单）

| 症状 | 原因 | 修复 |
|---|---|---|
| 玩家不知道该干什么 | 第 1 题 requires 太多线索 / 没有教学题 | 降低首题门槛，prompt 写得更具体 |
| 线索卡看不出用途 | 线索 text 太抽象 | 补具体名词与数值（时间、颜色、金额） |
| 推理变成穷举 | 答案组合可能性太多 | 减少单题卡池干扰、在 prompt 中限定"几条" |
| 玩完 10 分钟就通、无回味 | 信息一次给全、无渐进解锁（"线索全摆在明面"） | 深层文档改 requires_findings 分批解锁；关键线索移入 keywords/dig/hidden；补 locked_hint |
| 玩家点段落直接拿线索、没有发现感 | 所有线索块都用金线直摘 | 证词/报告类线索改 keywords 圈选，字眼藏在正文自然语句里（颜色/时间/数量/反常行为） |
| 破案没有爽感 | 结案演出太短/没有逆转节拍 | 按"亮证据→拆谎→指认→崩溃→宣判"重写 |
| 后期无题可做 | 议题解锁条件过严 | 检查 requires 链是否断档，补过渡议题 |
| 玩家卡死 | 线索不可达（校验警告） | 补 block 的 clue 字段或 initial: true |
| 逻辑牵强 | 结论跳步（缺中间环节） | 加一张中间结论卡，拆成两题 |
| 玩家对隐藏线索完全无感 | dig 引导语太明示 / hidden 段落太短没存在感 | 引导语写成好奇心而非指示；hidden 段落至少 2 句、埋在正常叙述中间 |

## 九、创作检查表（交付前逐项打勾）

- [ ] 一句话能说清诡计，且能从文档中推出
- [ ] 第 1 题是 2 卡教学题，10 分钟内可解
- [ ] 每条非初始线索都有来源段落
- [ ] 每个结论都有议题产出，且至少被一个后续议题/结案使用
- [ ] 存在 1-2 个红鲱鱼，且可被排除
- [ ] 难度 3+ 时：深层文档由结论解锁（占比 ≥ 40%）、dig 至少 1-2 处、关键线索不全在明面、带 requires 的议题均有 locked_hint
- [ ] 证词/报告类线索默认用 keywords 圈选（每项均为正文的连续子串；字眼是线索的**必要关键处**，玩家逐处圈齐才收录，2-10 字）
- [ ] 高难度 prompt 不预告答案张数（让玩家自己判断材料够不够）
- [ ] 难度 4-5 时：三重翻转的每层有独立引爆点、由上一层解锁的材料引爆；干扰证据均预埋自反点
- [ ] 结案 required_findings 体现"洗冤 + 擒凶"双重满足
- [ ] 结案演出 ≥ 8 句，含 flash_text「异议！」
- [ ] 校验脚本 0 错误、可达性警告清零
- [ ] 难度与用户预期匹配（问过用户或按 1-2 级起步）
